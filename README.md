# course-design-desk

把「课程设计」拆成五卷固定流程的施工台：登记项目 → 照路线做 → 卡住查原因 → 做完留档。

## 怎么打开

下载 `index.html`，双击即可。单文件，打开时不加载任何外部资源，断网也能用。

## 这份代码怎么来的

代码主体由 AI 生成。产品定义（五卷结构、7 阶段 35 点路线、10 类诊断表）、验收标准、bug 定位由我完成。

我在这份代码上做的事：定结构、卡边界、写验收断言、定位 1 像素级错位。
