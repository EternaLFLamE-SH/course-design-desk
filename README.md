# course-design-desk

**这是什么**：一个把「课程设计」拆成五卷固定流程的施工台 —— 登记项目 → 照路线做 → 卡住查原因 → 做完留档。

**正式站在哪**：https://course-design-desk.app.workbuddy.host/?sharecode=5PFMZ7M4NS

**本仓库仅存源码，不可直接运行**：登录、云数据库、「问 AI」审批都依赖云服务；下载 `index.html` 双击只能看到界面，这些功能全部不可用。要看能用的版本，点上面的正式站。

---

## 它是干什么的

把一次课程设计拆成五卷：**立项 → 路线 → 施工 → 诊断 → 归档**。

- 路线覆盖 **7 个阶段、35 个检查点**，勾掉一个自动收起上一级
- 卡住时按概率排序 **10 类常见故障**，不用从头翻文档
- 做完留档，下次同类项目直接复用

## 怎么打开（仅限看界面）

下载 `index.html`，双击即可。单文件，打开时不加载任何外部资源，断网也能用 —— 但只能看界面和本地草稿，云端功能需要正式站。

## 这份代码怎么来的

代码主体由 AI 生成。产品定义（五卷结构、7 阶段 35 点路线、10 类诊断表）、验收标准、bug 定位由我完成。

我在这份代码上做的事：定结构、卡边界、写验收断言、定位 1 像素级错位。

## 线上版本的权限边界

看和填随便用。只有「问 AI」这一功能需要管理员（我）审批 —— 审批状态由数据库权限规则锁定，前端改不了。

## 技术说明

- 单文件交付，214 KB，打开时不加载任何外部资源
- 云数据库负责登录与数据存储，权限规则（RLS）管审批状态
- 不依赖任何前端框架与构建工具
